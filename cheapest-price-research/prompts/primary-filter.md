## タスク

中国輸入物販の最安値リサーチで、対象商品と同一商品の可能性がある候補を 1 次フィルタする。

**1 次フィルタの目的**: 「明らかに別商品」を弾く。細部の決定打 (柄の細部・素材の質感・キルト目の幅など) は次段の最終判定で説明文と全画像を見て判定するので、ここでは保守的に拾う (**取りこぼしより誤包含を許容**)。

## 同一商品判定の前提

メルカリの中国輸入品は、出品者が他出品者通報リスクを避けるためタイトル・画像・説明文を意図的に変えて出品する慣習がある。よって「タイトル文字列の一致」ではなく **実体属性 (色・サイズ・個数・セット数・柄・素材・用途) の一致** で同一商品を判定する。

別商品扱いになる軸:

| 軸 | 例 |
|---|---|
| 色 | 白 / 黒 / ベージュ / ブラウン / シルバー / ゴールド 等 |
| サイズ | S / M / L / XL、A3 / A4 / B4、80×120 等 |
| 個数・セット数・容量 | 2 個セット / 5 枚セット / 500g / 100 枚 等 |
| 柄 | 無地 / 花柄 / チェック / 迷彩 等 |
| 素材 | 本革 / 合皮 / ナイロン / ポリエステル 等 |
| 用途・機能 | ショルダーバッグ / トートバッグ / クラッチバッグ 等 |

## 画像優先の原則

画像と説明文・タイトルに矛盾がある場合 (例: 画像が黒、タイトルに「白」と書いてある等) は **画像を優先** する。タイトル・説明文は出品者が誤記する/省略することがあるが、画像は実物そのものを示す。

## 1 次フィルタの判定基準

各 rank の候補について、以下のどちらかを判定する:

- **採用** (`candidate`): 対象と同一商品の可能性あり (画像とタイトルから明らかな別商品 NG が無いもの)
- **却下** (`rejected`): 明らかに別商品 (例: 色が違う / 形状が違う / カテゴリが違う / 個数が違う / セット数が違う)

「迷ったら採用」が原則。最終判定では説明文と全画像で精査するので、ここで切り過ぎない。

## 出力

`{OUTPUT_JSON_ABS_PATH}` に以下の JSON 形式で書き出す:

```json
{
  "sheet": {SHEET_NO},
  "rank_range": [{RANK_RANGE_START}, {RANK_RANGE_END}],
  "candidates": [
    { "rank": 3, "reason": "色 (黒)・形状 (V スタッズ) が対象と一致" },
    { "rank": 7, "reason": "形状・色が一致、個数は不明だが画像から単品と推定" }
  ],
  "rejected": [
    { "rank": 1, "reason": "色違い (シルバー)" },
    { "rank": 2, "reason": "別カテゴリ (キーホルダー)" }
  ]
}
```

- `candidates` と `rejected` で **全 20 件 (シート内の全 rank)** を網羅すること
- `reason` には判定軸 (色 / 形状 / カテゴリ / 個数 等) を必ず書く

- 採用候補の rank と reason の一覧
