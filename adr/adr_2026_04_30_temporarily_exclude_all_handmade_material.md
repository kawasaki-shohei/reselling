# ADR: ハンドメイド素材販売を暫定的に一律除外

**日付**: 2026-04-30

## ステータス

採用 (Accepted)。暫定対応。将来 (リサーチリソースが取れた段階) で見直し予定。

## 決定

ハンドメイド素材販売 (生地反物・プリント生地・シーチング・刺繍リボン素材・刺繍生地・ファスナー素材セット・ビーズ素材セット・チュールレース 等) を **現時点では一律で仕入れ候補から除外** する。

具体的には:

1. `procedures/exclude_by_keywords/keywords.json` の `handmade` カテゴリの「ハンドメイド」キーワード notWith から、素材販売を保護していた語 (生地 / 布地 / ファスナー / シリコンモールド / レジン / ビーズ / ステンシルシート / 型紙 / デザインボード 等) を削除する
2. 文字列マッチで素材販売を識別できるキーワード (生地 / 反物 / シーチング / オックス / チュールレース 等) を `handmade` カテゴリに追加する (誤爆チェックの上)

| 刺繍リボン素材セット | 0 件 |
| ビーズ素材セット | 0 件 |
| チュールレース生地 | 0 件 |
| ファスナー素材 | 1 件 (▲「一旦やめ」、実仕入れには至っていない) |

リサーチでは仕入れ候補として複数回残ってきている (`reports/2026/04/2026_04_28_01_メルカリ売れ筋リサーチ_keep.csv` で 20 件以上、`reports/2026/04/2026_04_16_02_メルカリ売れ筋リサーチ_04_12差分.csv` で 5 件) が、いずれも実際の仕入れには至っていない。

### Sonnet コスト削減

実績的に最終仕入れ候補に残らないため、第 4 段階 (画像判定 Sonnet) で再判定するのは Sonnet コストの無駄。

## 代替案

- **A: 2026-04-19 の方針 (別扱い = keep) を継続**: 実績的に最終仕入れに至らないので Sonnet コストの無駄。却下。
- **B: 商品を見て個別判断**: 個別判断ルールを作るには相当の調査時間が必要。現時点でリソースなし。却下。
- **C (採用): 暫定一律除外**: 現時点では除外、将来リサーチリソースが取れた段階で本 ADR を見直し、個別判断ルールを設計する。

## トレードオフ

- **デメリット**: 将来仕入れ候補になり得る商品 (ファスナー素材・パラコード・刺繍リボン素材 等) も今は除外される。リサーチリソースが取れて本 ADR を見直すまでこれらは仕入れ候補に残らない
- **メリット**: 第 4 段階画像判定の対象削減 (Sonnet コスト節約)、現時点で仕入れ実行に進めない商品をリサーチパイプラインから外し、既存の仕入れ可能カテゴリにリソースを集中できる
- **将来**: リサーチリソースが取れた段階で本 ADR を見直し、`notWith` の保護リスト復活 or 別カテゴリで個別判断ルールを設計する (新 ADR で本 ADR を Superseded する想定)
