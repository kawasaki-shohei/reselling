# ADR: ファッションカテゴリをリサーチ対象から除外

**日付**: 2026-08-16

## ステータス

採用 (Accepted)

## コンテキスト

collect 段階（`research/collect.js`）は全カテゴリを収集対象としており、生データに占める root カテゴリ「ファッション」（rootCategoryId: 3088）の割合は 24.6%（2026-07-17 収集分 20,690 件中 5,085 件）と最大級である。収集後の各段階（辞書拡張・画像判定 Sonnet 等）の入力もこの分だけ増え、トークンコストを押し上げている。

一方、ファッション商品はキャミソール等、過去のリサーチで仕入れ候補に残った実績もある。過去 3 run（2026_05_15 / 2026_06_02 / 2026_06_16）の仕入れ候補 1,583 クラスタのうち 603 クラスタ（約 4 割）がファッション root 由来だった。つまり「候補は出るが除外する」という判断であり、その理由を記録する必要がある。

## 決定

root カテゴリ「ファッション」に属する商品を、collect 段階で収集対象から除外する。

## 根拠

物販オーナーの判断として以下の理由が伝えられた（2026-08-16、開発者経由）。

1. **自動化・判定が難しい**: 同一商品であるかどうかの判定・判断がしにくい。
2. **トレンドが読みにくい**: 何が当たるか分かりづらい。
3. **調査コストと利益率のミスマッチ**: 候補を選んできたとしても、仕入れ確定まで調査を完了させるのにかなり時間がかかる。さらにそれができたとしても、利益率が低い可能性が高い。

## トレードオフ

- **デメリット**: 過去実績では仕入れ候補の約 4 割（3 run 通算 603 クラスタ）がファッション由来であり、これらは今後候補に残らない。キャミソール等、過去に候補入りした商品系統も対象外になる
- **メリット**: 生データが約 25% 減り、以降の全段階（辞書拡張・画像判定 Sonnet・レポート化）の入力とトークンコストが削減される。候補に残っても仕入れ確定に至りにくい商品群の調査コストを、他カテゴリに振り向けられる
- **将来**: この判断を見直す場合は新 ADR で本 ADR を Superseded にする

## 補足: ハンドメイド素材も collect 段階の除外に含める（2026-08-16 追記）

collect 段階のカテゴリ除外リストを設計する過程で、ハンドメイド素材（ファスナーセット・マクラメ糸・刺繍リボン・毛糸・レジン液 等）を除外に含めるかが論点になった。過去 3 run で 41 クラスタが仕入れ候補に残った実績があるためである。

以下の判断で **collect 除外に含める** とした。

- 物販オーナーの回答（[ADR 2026-04-30](./adr_2026_04_30_temporarily_exclude_all_handmade_material.md)）の通り、このあたりは仕入れ（選定リサーチ）が難しく、今は仕入れの調査に時間を割けないため仕入れ対象になっていないだけであり、将来的に余裕ができたらやっていきたい領域である
- 仕入れ確定リスト（改良版【中国輸入】利益計算・原価計算 - リスト、2026-08-16 時点 259 商品）を確認したところ、ハンドメイド素材の仕入れ実績は 0 件だった
- したがって、**今の調査で仕入れ候補として残っている商品も除外対象とする**。候補に残っても最終的な仕入れ確定までは至らないためである
- 将来、ファッション系も含めてリサーチ対象カテゴリを調整するときに、これらもあわせて見直す
