単独の単語ではブランド名と結びつかないが、組み合わせで模造品と判定できるもの。

| キーワード組み合わせ | 想定ブランド | 備考 |

- 「クロム」単独ではクロムネイル / クロムパウダー / クロムパーツ (金属光沢ネイル技法) 等の一般用語。ブランドとは無関係なので単独除外禁止

## 3. 食品・薬機法・電波法 (PDF に具体名がないもの)

PDF では「化粧品」「医薬部外品」「Bluetooth」等カテゴリで禁止。下記は商品名からカテゴリを直感しにくいものだけ。

| キーワード | 分類 | なぜ PDF だけでは分かりにくいか |
|---|---|---|
| にっぽんselect とろリッチ | 食品 (ペットフード) | 商品名だけではペットフードと分からない |
| 黒糖姜棗茶 / 八宝茶 | 食品 (健康茶) | 「黒糖」を色判定で拾いやすいが食品 |
| tfit コンシーラー | 化粧品 (薬機法) | 「tfit」がブランド名、初見では判別難しい |
| クレスト 3Dホワイト | 歯磨き粉 (医薬部外品) | 歯磨き粉と分かりにくい商品名 |
| Colgate | 同上 | 海外歯磨き粉ブランド |
| マグネット式つけまつげ | 化粧品 + 磁気 | 「つけまつげ」で化粧品と分かるが磁気も追加 NG 要素 |
| 睡眠用イヤホン | 電波法 + PSE | Bluetooth 内蔵のため |
| スマートウォッチ (T900 Ultra2 等) | 電波法 + PSE | 「時計」に見えて実は Bluetooth 電子機器 |
| iPhone 充電器 純正 | PSE + 純正偽装 | 純正表記は商標偽装リスク |

### 判定に注意 (一律除外しない)

| キーワード | 理由 |
|---|---|
| Bluetooth + 付属品 (ケース・スタンド等) | 本体が電波法対象。付属品で Bluetooth 機能を使わなければ OK の場合あり |
