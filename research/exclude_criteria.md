# 除外判定基準 (単一ソース)

画像 + タイトルで除外カテゴリ該当を判定するための基準。**本番の画像除外 (`research/image_exclusion_prompt.md`) と精度検証の unflagged 判定 (`procedures/exclude_by_keywords_precision_check/agent_prompt_unflagged.md`) の両方がこの内容を共有する。** 二重管理を避けるため判定基準はここだけで編集し、各プロンプトはビルド時に `{CRITERIA}` プレースホルダへこのファイルの中身 (下記水平線の下、「## 除外カテゴリの定義」以降) を差し込む。

判定基準を更新するときはこのファイルを直接編集する (両プロンプトに自動で反映される)。

---

## 除外カテゴリの定義

カテゴリ名・キーワードは `procedures/exclude_by_keywords/keywords.json` に対応。各カテゴリの法令根拠は `references/注意商品.pdf` (page 5-6 が法令一覧、page 1-4 がブランド・キャラ例) と対応する。ここでは画像判定で必要な判定基準を PDF 原文準拠で示す (キーワードの重複列挙はしない)。**疑わしい/判定迷う場合は PDF を直接 Read して原文を再確認すること** (詳細は判定フローを参照)。

1. **food** (食品衛生法、PDF page 5): 食品・食器類・調理器具 (金属トング・菜箸など食品に触れる器具を「単純な金属雑貨」と誤認して keep しない)、6 歳以下対象の商品・おもちゃ・笛 (口に付けるものは特に注意)、風船、ぬいぐるみ。※玩具系は仕入れを避けるのが無難
2. **plant_quarantine** (植物防疫法): 生きている植物・苗・種子・盆栽・多肉・サボテン (造花は除く)
3. **medical** (薬機法 = 医療機器、PDF page 5): 医薬品・医療機器 (医療用サポーター・矯正器具)、血圧計、体温計、パルスオキシメーター、サージカルマスク、医療用針 (※釣り具などの針も仕入れを控える)。化粧品系は cosmetics_yakki で扱う
4. **cosmetics_yakki** (薬機法 = 化粧品・医薬部外品、PDF page 5): 化粧品、メイク道具、口紅、香水、スキンケア、洗顔料 (洗顔パフは雑貨で keep)、日焼け止め、シャンプー、歯磨き粉、医薬部外品、度付き眼鏡、サウナスーツ、ナイトブラ、補正下着、かみそりなど直接肌につけるもの。※バストアップ・○○が治る等の効果効能を謳う表現は NG
5. **character_copyright** (商標権・知的財産権侵害、PDF page 1, 4): アニメ/漫画/ゲーム/K-POP キャラ本体かロゴ。サンリオ/ディズニー/ポケモン/BTS/鬼滅/ちいかわ/NCT/SEVENTEEN/TWICE/原神/葬送のフリーレン/スパイファミリー/呪術廻戦/ワンピース/ドラえもん/アンパンマン/スヌーピー/LABUBU/ミッフィー/モンチッチ/POP MART/ひつじのショーン 等。**キャラクターの顔が入っていない場合も NG** (PDF 原文)。※版権柄なしの「推し活」汎用雑貨 (痛バッグ・トレカローダー・アクスタスタンド等) は **keep**
6. **brand_imitation** (商標権・知的財産権侵害、PDF page 1-3): ブランド名またはロゴが連想されるデザイン (下記連想 NG 一覧)。クロス/十字架モチーフのネックレスを「ノーブランドの雑貨」と誤認して keep しない (連想 NG の Chrome Hearts に該当)。自動車メーカー名・車種名・グレード名 (例: MINI/MINIクーパー、アルファード、Executive Lounge 等) を冠した非純正品 (エンブレム・車種専用サンシェード等) も商標権侵害として exclude。「カーアクセサリー/汎用カーパーツ」と誤認して keep しない。※異常な安価で販売されているハイブランド風デザインはコピー品の可能性が高い (PDF page 2 例示)
7. **electronics_check** (電気用品安全法 PSE / 電波法、PDF page 5): **LED を使用している物全般** (LED ライト・LED ナンバープレート・字光式ナンバー・LED フォグ・LED ウインカー・LED 装飾品・光るぬいぐるみ/キーホルダー・**車用 LED/HID ヘッドライトバルブ・車用電装パーツ全般 (バルブ・ライト類)** 等。**LED の有無で判断、用途は問わない**。車用バルブを「車のパーツ=雑貨」と誤認して keep しない)、コンセントを使う商品・電化製品全般、モバイルバッテリー、Bluetooth を使用する商品 (ワイヤレスイヤホン/スピーカー、スマートウォッチ 等)、ヒートガン、電動ポリッシャー
8. **handmade** (実務判断、ADR `adr/adr_2026_04_30_temporarily_exclude_all_handmade_material.md`): 作家品、手作りジュエリー、ぬい服本体、手描きイラストに加え、**ハンドメイド「用」素材も一律 exclude**。具体例: 生地反物・プリント生地・シーチング・オックス・チュールレース・刺繍生地・布地・刺繍リボン素材・ファスナーセット・ビーズ素材セット・レジン・ステンシルシート・型紙・シリコンモールド・デザインボード 等。「○m カット」「○m×N本セット」等の素材販売を含む。理由: 暫定的に一律除外 (将来リサーチリソースが取れた段階で見直し予定)
9. **underwear** (下着類、PDF page 5): ナイトブラ・ブラジャー・ショーツ・ボクサーパンツ・サニタリーショーツ・ガードル・ヌーブラ・T バック等。※新品と証明できる実物写真の掲載が必須となるため回避
10. **sourcing_unavailable** (実務判断、PDF 該当なし): アリババで仕入れ困難な商品。
    - 古い世代の iPhone (例: iPhone 12 / 12 Pro / 12 mini / SE2 / SE3 / 8 / 7 等) のみ対応のスマホケース・手帳型ケースは exclude。最新 2-3 世代も対応と明記されていれば keep。「古い」の判定は判定者の知識に委ねる (1 世代ズレ許容)
11. **media** (実務判断、PDF 該当なし): CD・DVD・Blu-ray、および **読み物としての本** (一般書籍・小説・エッセイ・学習書・問題集・参考書・図鑑・写真集・語学書・専門書・コミック・漫画) は exclude。物販オーナー方針「本は全くいらない」。**画像を見て本だと判別できれば** タイトルに本系キーワードがなくても exclude する (辞書漏れ救済)
    - ただし以下は **keep**: ノート / 手帳 / 日記帳 / バインダー / ファイル / シールブック / ステッカーブック / シール集 (= シール販売) / 写真アルバム / フォトフレーム / 絵本素材 (= コラージュ素材) / カレンダー / 楽譜 / カタログ
    - 迷ったら keep
12. **korea** (実務判断、PDF 該当なし): 韓国製・韓国系商品全般 (韓国コスメ・韓国ファッション・韓国子供服・韓国アクセサリー・韓国学習書・韓国の交通カード Tmoney・気候同行カード・ハングル文字商品 等)。物販オーナー方針「韓国は基本いらない」
13. **psc** (消費生活用製品安全法 = PSC マーク、PDF page 5-6): 乗車用ヘルメット・チャイルドシート・浮き輪等の PSC 特定製品。**子供用シートベルト・補助ベルト・キッズベルト (ジュニアシートベルト等) を含む**。子供用の補助シートベルト等を「除外要素なし」と誤認して keep しない

## その他の法令注意点

- 本革 (関税高) / 動物の皮・漢方薬 (ワシントン条約)
- 下着類 (新品証明必要で回避) / 珪藻土マット (石綿規制)
- ヘルメット・チャイルドシート・浮き輪 (PSC マーク)
- 温度計・圧力計・スケール (計量法) / 拳銃・刀・刃物 (輸入禁止)
- 液体・電池・強磁気商品 (空輸禁止)

## 短語誤爆に惑わされない

タイトル中の「ウタ」「シュガ」「ガム」「マカ」「オレンジ」「チョコ」「ハンドメイド」は flagged 側の辞書誤爆語。unflagged 側の判定では画像で実体を確認すれば正しく判断できる。
